# Barnacle goose grazing effects on soil properties on Storholmen, Svalbard

R code for the statistical analysis in the course report *Barnacle goose (Branta leucopsis) grazing effects on soil properties on Storholmen, Norway* (AB-201 Terrestrial Arctic Biology, The University Centre in Svalbard (UNIS), 2026).

**Authors:** Catharina ten Cate Aasen, Tea Fredin, Kaja Hosen, Greta Jacobs, Olivia Zamrykut

## What the code does
`analysis tests whether barnacle goose faecal counts are associated with soil moisture, pH and C:N ratio, using permutation-based linear regression. It also runs pairwise correlations between the soil variables. It uses the `tidyverse` and `infer` packages.

## Data
The raw data are available at https://doi.org/10.21343/r3g4-mn70.
